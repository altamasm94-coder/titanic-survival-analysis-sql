Titanic Survival Analysis — SQL

Project Overview

A SQL project exploring Titanic passenger data to investigate survival patterns and passenger characteristics.

Objectives

- Examine survival rates among passengers.
- Explore survival patterns across passenger groups.
- Analyse passenger demographics where the data permits.
- Practise answering analytical questions using SQL.

SQL Concepts

- SELECT, WHERE and ORDER BY
- Aggregate functions
- GROUP BY and HAVING
- JOINs, subqueries or window functions, where used

Project Files

- "titanic_survival_analysis.sql" — SQL queries used for the analysis.

Key Learnings

Practised using SQL to explore a dataset, summarise passenger information and investigate patterns in survival outcomes.
